## 移动端布局修复（用户："mobile上访问web，根本不可用，布局有问题"）

### P0：Copilot 面板在窄屏永久遮挡 → 打开即白屏
`index.css` 里 `@media (max-width:768px) { .copilot-shell { position: fixed !important; width: min(92vw,420px) !important; z-index:1000 } }`。
但 `.copilot-shell` 类名在 `open===false` 时**依然在 DOM 上**（组件靠内联 `width:0` 收起），
`!important` 压过内联样式 ⇒ 窄屏永远一块 92vw 白板浮在 z-index 1000，内容又因 `{open && …}` 不渲染
⇒ 用户看到一片空白。**这就是"根本不可用"的直接原因。**

教训：**结构问题要用结构解决，别用 `!important` 去盖内联样式。**
改为 `useIsMobile`（新增 `src/hooks/useIsMobile.ts`，断点 768）+ 窄屏关闭时 `return null`，
打开时渲染 fixed 浮层 + 点遮罩关闭；拖拽改宽手柄窄屏不渲染。
`index.css` 只留纯样式（`.app-header`/`.app-content` 内边距 24→12），
**且组件不再用内联重复设置同一属性**——否则又得靠 `!important`，正是 bug 成因。

配套：Header 横向溢出（标题+Tag+2 按钮 ≈450px 挤在 375px）。`Layout.Header` 默认
`height:64`+`line-height:64` **不允许换行**，折行会被裁 ⇒ 窄屏放开 `height:auto`+`flexWrap:'wrap'`，
标题缩短、按钮只留图标。

### ① A-9：上一版根因诊断是错的，已推翻重写
旧诊断「纯中文无空白分词，token_set_ratio 把合理改写判为漂移 → 越保守越重复」，实测**相反**：

| 改写类型 | option-vs-canonical | 判定（≥45） |

| **只改题干、选项照抄** | stem 55 / **整体 90** | **近重复** |

**真实根因在代码不在数据**（两处）：
1. `assemble-variants.ts` 旧行 `options: entry.options ?? canonicalOpts` —— 草稿没给选项就

题干在整体指纹里只占 ~1/11 权重，**改题干不可能拉低相似度**。这就是 dup 度量改成「只比选项」的依据。

修了 5 处：去重上提 domain（`findNearDuplicateVariants` + `VARIANT_DUP_THRESHOLD`）、
度量换 `cjkDice`、比较对象换选项级 `variantOptionText`、assemble 选项必填 + 落盘前去重温、
validate-variants 复用同一函数。验证：fixtest 双门禁全过，sibling 90 → <70；旧草稿 exit 1 未落盘。

## 踩坑
- **本仓库 Bash `grep` 会静默返回空**（模式明明命中，exit 0 无输出），MD 文件和 package.json 都中招。
  改用 **Grep 工具**即可，不要浪费轮次怀疑文件内容。
- **Grep 工具本身也会挂**：`SandboxError: Failed to spawn sandbox-exec: Argument list too long`。
  此时退回 Read/Glob。
- **Shell 会整体失效**：所有 Bash 调用返回 `Exit Code: 127` + 空 stdout/stderr，
  连 `/bin/echo`、`true`、`export PATH=...` 都一样；`dangerouslyDisableSandbox` 也救不回来。
  文件工具（Read/Edit/Write/Glob）不受影响。遇到时**不要再重试**，直接切文件工具推进，
  并把「未验证」显式记进 CHANGELOG。
- `npm run question:validate-variants` 报 `vite-node: command not found`（`.bin` 被之前
  rename 失败搞坏了）。绕过：直接 `node node_modules/vite-node/dist/cli.mjs scripts/xxx.ts`。
  同理 vitest 用 `node node_modules/vitest/dist/cli.js run`。
