## 踩坑：批量改题库 JSON 不能 `JSON.stringify(_, null, 2)`

题库里两种排版风格并存：`evaluation.json` 一类是展开式（数组逐元素换行），`claude-blog-2026-08.json` / `foundational-and-intermediate.json` 一类是紧凑式（嵌套对象压在一行）。整文件 `JSON.stringify` 会把紧凑式全量炸开——28 题的改动产生 2700 行 diff。

解法：外科式文本补丁（`/tmp/surgical_patch.mjs` 的做法）——字符串感知的 JSON 扫描器定位 `id` 所在对象 span，只改这一块，按「该块是否含 `\n {6,}"`」判断展开/紧凑风格，用同样的风格插入新字段；插入点固定为 `misconceptions` 放在 `"formats"` 之前（与 schema 字段顺序一致）、`misconceptionMap` 紧跟 `"answer"`。写完必须 re-parse 并逐题比对非目标题，确认「非目标题漂移 = 0」。

**插入属性时的逗号处理**：`A , B` 要变成 `A , NEW , B`；若原 `A` 是最后一个属性（后面没逗号），则变成 `A , NEW`。忘了这层会让 JSON 非法或产生尾逗号。
