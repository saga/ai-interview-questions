## Structured Knowledge RAG Phase 1（ADR-063）

按 `docs/improvement_plan/ knowledge_base_for_copilot.md` 落地：**不做 Vector RAG**，先做结构化检索。

新增 `src/domain/knowledge/`：
- `types.ts` — `KnowledgeDocument` / `KnowledgeHit` / `RetrievalScope` / `RetrievalMode` / `HYBRID_WEIGHTS`
- `documents.ts` — KnowledgeNode/Question 投影；真值（`explanation` / `choice.answer` / `referenceAnswer`）隔离进 `sensitiveText`
- `index.ts` — 内存倒排索引，BM25（k1=1.2 b=0.75）；中文用「单字 + bigram」双通道
- `graph.ts` — 1 跳扩展 seed 1.0 / prerequisite 0.8 / related 0.6 / dependent 0.45
- `retrieve.ts` — 混合评分 0.40 lexical + 0.25 metadata + 0.20 graph + 0.15 semantic（Phase 1 按比例回填前三项）

应用层 `src/application/conversation/knowledgeCapability.ts`：确定性 query planner（scope + 答案安全模式），不额外消耗 LLM。

关键决策：
- **答案安全模式是检索层硬裁剪**（`renderDocument`），不是 prompt 请求模型自觉。
- scope 兜底链只保留 `current_question → topic`；`topic` 不回退 global（错证据比没证据更糟）。
