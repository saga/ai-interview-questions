# Prompt 输入与输出格式基础

## 本节要解决的问题

清楚说明模型任务和期望的返回形式.

Cortex GenAI 应用。明确任务输入、模型或检索路径、输出契约、质量指标、数据权限和失败处理。

本教程只对应知识点 `cortex-prompt-output-basics`。目标是理解其机制、适用边界和验证方法，不把相邻知识点合并成一个大章。

## 核心知识

### 清楚说明模型任务和期望的返回形式.

机器学习流程要保存训练数据版本、特征定义、时间点、代码和模型版本，并使用独立验证集评估。避免未来信息泄漏；模型注册不等于业务效果已验收。

### 在提示中描述任务、必要上下文、格式和限制.

Agent 可靠性来自工具契约、调用身份、权限、停止条件、失败恢复和可审计轨迹。Thread 不是业务状态库；工具返回内容是待验证数据，不是系统指令。

### 明确的输出要求能减少格式不一致，但不能保证语义无误.

业务指标必须定义分子、分母、过滤条件、时间口径、事实粒度和可加性。语义层能表达已确认的业务定义，却不能修复底层错误键、粒度或多对多关系。

## 工程实施步骤

1. 定义任务类型、代表性输入、目标输出 Schema、敏感级别和质量标准。
2. 保留模型/提示版本、来源、运行参数、权限过滤和异常状态。
3. 用独立样本评测正确性、引用、拒答、延迟、吞吐和真实成本。

## 场景分析

业务用户提出涉及企业文档或结构化指标的问题。请确定模型/检索路径、证据来源、输出校验和访问过滤。

将场景转换为明确输入、状态变化和预期输出。逐项检查本节核心要求，区分配置事实、运行证据和待验证假设。缺少权限、版本、数据样本或官方行为证据时，明确记录未知项，不用猜测补齐。

## 常见误区

- **误区：** 提示越含糊越容易得到稳定格式
  **纠正：** 回到本知识点的输入条件、执行边界和验证证据，确认判断成立的前提，不要把简化经验当普遍规则。
- **误区：** 只要求 JSON 就能保证内容正确
  **纠正：** 半结构化字段读取时区分字段缺失、JSON null、SQL NULL 和类型转换失败。FLATTEN 会把数组展开成行，必须检查展开前后的粒度和连接基数。
- **误区：** 模型天然知道所有内部业务术语
  **纠正：** 机器学习流程要保存训练数据版本、特征定义、时间点、代码和模型版本，并使用独立验证集评估。避免未来信息泄漏；模型注册不等于业务效果已验收。
