# Iceberg Catalog、外部引擎与权限边界

## 本节要解决的问题

理解 Iceberg Catalog、对象存储与消费引擎之间的元数据协调和访问控制边界。

Iceberg / Lakehouse。理解数据文件、表元数据、Catalog、写入协调、计算引擎和维护责任。

本教程只对应知识点 `iceberg-external-catalog-integration`。目标是理解其机制、适用边界和验证方法，不把相邻知识点合并成一个大章。
