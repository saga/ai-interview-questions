# 绩效归因、因子暴露与市场状态

## 本节要解决的问题

组合本月跑赢基准 1.9 个百分点。投资经理认为超额收益主要来自科技股选股；绩效团队的初步报告却显示，行业配置贡献为负、证券选择贡献为正，另有一部分收益没有被解释。

归因分析要把相对基准的超额收益分解到投资决策；因子模型解释组合对市场、规模、价值、利率、信用等系统性风险驱动的暴露；市场状态分析则用来观察这些暴露和收益来源在不同环境下如何变化。三者回答的问题不同，不能把行业超配直接解释成因子暴露，也不能把历史回归系数当作未来收益预测。

## 核心知识

### 先区分收益贡献、相对基准归因和风险归因

| 分析 | 回答的问题 | 需要的输入 |
|---|---|---|
| Return Contribution | 哪些证券/行业贡献了组合的绝对收益？ | 组合权重、资产收益 |
| Return Attribution | 组合相对基准的超额收益来自哪些投资决策？ | 组合/基准权重、分组收益、基准总收益 |
| Factor Return Attribution | 超额收益与哪些系统性因子收益相关？ | 组合超额收益、因子收益、估计窗口 |
| Risk Attribution | 哪些持仓或因子贡献了组合风险？ | 权重、风险模型、协方差或因子风险 |

绩效归因的目标是解释相对基准的表现，并把结果与管理人的主动决策联系起来。若没有合适基准，绝对收益贡献仍然有用，但不能把它称为相对基准的 Return Attribution。

归因框架应与投资决策过程匹配。若策略按资产配置、行业配置和证券选择逐层决策，就应确保数据分组和归因模型能够对应这些决策层级。

### Brinson–Fachler 将单期超额收益拆成配置、选择和交互效应

对某一行业或资产组 \(i\)，定义：

- \(w_i\)：组合在该组的权重；
- \(W_i\)：基准在该组的权重；
- \(r_i\)：组合在该组的收益；
- \(b_i\)：基准在该组的收益；
- \(b\)：基准整体收益。

Brinson–Fachler 三项效应为：

\[
A_i=(w_i-W_i)\times(b_i-b)
\]

\[
S_i=W_i\times(r_i-b_i)
\]

\[
I_i=(w_i-W_i)\times(r_i-b_i)
\]

其中 A 是 Allocation，S 是 Selection，I 是 Interaction。选择效应使用基准权重；配置效应将行业收益与基准整体收益比较。不要把 Brinson–Hood–Beebower 的配置公式和 Brinson–Fachler 的配置公式混用。

以科技行业为例：

| 输入 | 数值 |
|---|---:|
| 组合权重 \(w_i\) | 40% |
| 基准权重 \(W_i\) | 30% |
| 组合行业收益 \(r_i\) | 8% |
| 基准行业收益 \(b_i\) | 6% |
| 基准整体收益 \(b\) | 5% |

计算：

- 配置：\((40\%-30\%)\times(6\%-5\%)=+0.10\%\)，即 +10bp。
- 选择：\(30\%\times(8\%-6\%)=+0.60\%\)，即 +60bp。
- 交互：\((40\%-30\%)\times(8\%-6\%)=+0.20\%\)，即 +20bp。

科技行业合计贡献 +90bp。它不等于整个组合的超额收益；还需要计算其他行业并核对总效应。这个分解假设权重和收益使用相同单期区间，并采用一致的基准与资产分类。

在 Snowflake 中，先把证券级持仓和收益汇总到行业层，得到每个组合/基准/期间/行业一行的归因输入，再计算效应：

~~~sql
SELECT
  portfolio_id,
  benchmark_id,
  period_end,
  sector,
  (portfolio_weight - benchmark_weight)
    * (benchmark_sector_return - benchmark_total_return) AS allocation_effect,
  benchmark_weight
    * (portfolio_sector_return - benchmark_sector_return) AS selection_effect,
  (portfolio_weight - benchmark_weight)
    * (portfolio_sector_return - benchmark_sector_return) AS interaction_effect
FROM sector_attribution_input
WHERE period_end = '2026-11-27';
~~~

执行前要确认权重是期初还是期末权重、行业分类版本是否一致、现金和非基准资产如何处理。若有现金、杠杆、衍生品、币种或分类不匹配，可能出现残差；残差应单独解释，不能直接塞进某一项效应。

### 因子暴露表示组合对风险驱动因素的敏感度

一个常见的线性因子模型可以写成：

\[
R_{p,t}-R_{f,t}
=\alpha+\beta_{MKT}F_{MKT,t}
+\beta_{SIZE}F_{SIZE,t}
+\beta_{VALUE}F_{VALUE,t}
+\beta_{MOM}F_{MOM,t}
+\epsilon_t
\]

这里的 \(\beta\) 是组合对因子收益的历史敏感度，\(\alpha\) 是模型无法由所列因子解释的截距，\(\epsilon_t\) 是残差。具体因子定义、市场、币种、风险自由利率和频率必须由模型规范确定。

例如，组合对 VALUE 因子的 beta 为 0.35，不等于组合有 35% 的价值股权重；它表示在该模型估计窗口和样本条件下，组合超额收益对 VALUE 因子收益变化的估计敏感度。因子暴露也不是因子收益预测。

回归样本要对齐交易日、币种和收益频率。需要滚动估计时，应只使用估计日期以前的数据。若用全部历史样本拟合一个 beta，再将它解释为早期历史时点的已知暴露，就会引入未来信息。

### 市场状态用于分组观察风险和归因变化，不是一个固定标签

市场状态可以按可解释的经济变量定义，例如：
- 利率上行/下行；
- 信用利差扩大/收窄；
- 波动率高/低；
- 风险偏好改善/恶化；
- 流动性充裕/紧张。

状态边界应有明确指标、阈值和时间戳。若用聚类模型或状态识别模型，分类模型也必须只使用当时可获得的数据；不要先用整个历史样本聚类出“危机状态”，再把这些标签当作当年已经可知的事实。

分析重点是比较同一组合在不同状态下的行业权重、因子 beta、波动率、回撤和流动性。样本太短或状态切换太少时，应说明统计不稳定性，不能把某个阶段的高收益外推成稳定规律。

### 多期归因需要几何链接，不能直接把每月效应相加

单期 Brinson 效应通常使用算术收益分解；多期组合与基准收益则按复利几何链接：

\[
R=\prod_{t=1}^{T}(1+r_t)-1
\]

因此，月度 allocation、selection 和 interaction 的直接求和，通常不能等于整段期间的超额收益。把单期收益差简单复利也不一定能得到正确的多期归因结果。

长期报告应选用经过批准的多期链接方法（例如 Carino 等链接方法），并对所有效应一致应用。不能在同一报告中混用不同的链接方法，或根据结果是否好看而挑选归因期间。

### 归因报告要解释残差、币种和基准，而不只是列出效应表

归因结果要能与组合和基准的实际收益对账。以下因素经常产生残差或解释差异：
- 现金、杠杆、衍生品和空头处理；
- 外汇收益及基准是否对冲；
- 交易费用、税费和预提税；
- 权重与收益的期间错配；
- 基准成分变更、证券分类变更；
- 组合估值和基准数据源差异；
- 单期算术归因与多期几何链接。

报告要写明代表性组合或 Composite、基准、期间、算法、收益类型、链接方式及数据来源。CFA Institute 2026 年的 Return Attribution Reporting 指引也强调方法透明、一致性以及披露基准和计算口径；它不规定所有策略必须使用同一种归因模型。

## 工程实施步骤

1. 确定分析是 Return Contribution、Brinson Return Attribution、Factor Return Attribution 还是 Risk Attribution。
2. 固定组合和基准的代表范围、报告期间、收益频率、币种及基准版本。
3. 从证券级持仓生成期初权重、行业/资产组权重和相应总回报；确保证券分类版本在组合与基准间一致。
4. 生成行业归因输入，检查组合和基准权重合计、现金、衍生品、未分类证券和收益对账差额。
5. 按选定的 Brinson 变体计算 Allocation、Selection、Interaction；在数据层显式保存公式版本。
6. 使用历史因子收益和组合超额收益估计因子暴露，记录回归窗口、因子定义、币种和估计日期。
7. 使用滚动窗口观察 beta 稳定性，并通过样本外时期验证，不把全样本估计值回填为历史可知暴露。
8. 为市场状态定义有时间戳的指标与阈值，检查状态标签是否使用了未来数据。
9. 对多期归因采用统一的几何链接方法，核对链接后的分项效应与总超额收益。
10. 将残差、币种、现金、费用、衍生品和基准差异单独展示并解释。
11. 在 Snowflake 中保存原始输入快照、权重/收益汇总、模型版本、Query ID 和计算结果，支持复算。
12. 报告由绩效团队核对、组合经理解释投资决策；Agent 可以生成差异摘要，但不能把统计关联自动解释为投资因果。

## 场景分析

组合在某月跑赢基准 1.9 个百分点。科技行业超配 10 个百分点，组合科技股收益 8%，基准科技行业收益 6%，基准整体收益 5%。按 Brinson–Fachler 计算，科技行业的配置、选择和交互效应分别为 +10bp、+60bp 和 +20bp，合计 +90bp。

但这只解释了该行业的单期贡献。其他行业可能产生负效应，现金和币种也可能带来差异。绩效团队应将所有行业的效应加总，与组合和基准的实际超额收益对账，明确剩余残差。

另一个分析显示组合的成长因子 beta 在最近 6 个月从 0.2 升至 0.7。这个结果表示历史敏感度变化，不意味着组合一定会在成长股上涨时获得同样幅度的回报。需要检查持仓变化、样本窗口、市场状态和因子定义，再解释变化来自行业配置、个股暴露还是数据口径。

如果投资委员会问“为什么组合在加息阶段落后”，可以进一步按利率状态观察久期、成长因子、行业配置和估值敏感度；不能只根据一条回归 beta 就断言加息导致了全部落后收益。

## 常见误区

- **把配置、选择和交互公式混用。** Brinson–Fachler 的配置效应使用行业收益减基准总收益；不能用另一个 Brinson 变体的公式替代。
- **把超配某行业等同于配置贡献为正。** 只有该行业收益超过基准整体收益时，超配才会产生正的 Brinson–Fachler 配置效应。
- **把因子 beta 当成因子收益或资产权重。** Beta 表示模型估计的敏感度，不是未来收益预测。
- **把因子相关性解释成因果关系。** 回归系数会受模型遗漏、样本窗口和市场状态影响。
- **把所有月份的归因效应直接相加。** 多期收益具有复利特性，需要统一的几何链接方法。
- **只展示 Allocation 和 Selection，隐藏 Interaction 与残差。** 需要说明是否计算交互项、是否并入选择效应，以及剩余差异来自哪里。
- **用全样本分类结果回填历史市场状态。** 这会让历史状态标签使用未来信息。
- **把模型解释当成自动投资结论。** 归因描述过去的收益来源，不保证未来因果或表现。

## 完成标准

- [ ] 能区分 Return Contribution、Return Attribution、Factor Attribution 和 Risk Attribution。
- [ ] 能用 Brinson–Fachler 公式计算配置、选择和交互效应。
- [ ] 能解释基准整体收益在配置效应中的作用。
- [ ] 能理解因子 beta、alpha 和残差的含义与局限。
- [ ] 能用滚动、Point-in-time 数据分析不同市场状态下的暴露变化。
- [ ] 能说明单期归因和多期几何链接的差异。
- [ ] 能将归因效应与实际组合/基准超额收益对账。

## 自测

1. 某行业组合权重 40%、基准权重 30%，行业收益 6%、基准整体收益 5%。Brinson–Fachler 配置效应是多少？为什么不是简单用超配权重乘行业收益？
2. 同一行业的组合收益 8%、基准行业收益 6%、基准权重 30%。Selection Effect 是多少？它使用组合权重还是基准权重？
3. 组合成长因子 beta 从 0.2 上升到 0.7，能否解释为成长股权重增加 50 个百分点？为什么？
4. 为什么不能将 12 个月的 Allocation、Selection 和 Interaction 直接相加作为全年归因？
5. 用全样本聚类结果标记 2018 年的“危机状态”，再分析 2018 年的组合表现，可能产生什么偏差？
6. 单期归因分项加总与组合超额收益不一致。应先检查哪些输入和口径，而不是把差额任意放入 Selection？
