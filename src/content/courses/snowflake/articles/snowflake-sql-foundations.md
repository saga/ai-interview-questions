# SQL 基础语义、类型与对象边界

## 本节要解决的问题

以 Snowflake SQL 为目标环境掌握筛选、NULL、类型转换、对象命名和标准表约束的实际语义。

Snowflake 平台基础。区分持久化对象、计算资源、元数据服务、会话上下文和授权主体，再沿数据实际流动路径验证行为。

本教程只对应知识点 `snowflake-sql-foundations`。目标是理解其机制、适用边界和验证方法，不把相邻知识点合并成一个大章。

## 核心知识

### 正确解释 WHERE、HAVING、聚合及 NULL 三值逻辑，避免把 NULL 当作普通值

业务指标必须定义分子、分母、过滤条件、时间口径、事实粒度和可加性。语义层能表达已确认的业务定义，却不能修复底层错误键、粒度或多对多关系。

### 在时间、数值和半结构化字段上使用明确的数据类型与显式转换

半结构化字段读取时区分字段缺失、JSON null、SQL NULL 和类型转换失败。FLATTEN 会把数组展开成行，必须检查展开前后的粒度和连接基数。
