# CREATE OR ALTER 与数据库变更管理

## 本节要解决的问题

组合声明式对象管理、数据迁移脚本、依赖顺序与漂移检测。

Snowflake 工程交付与运维。重点是让配置、执行身份、变更、运行证据和恢复过程可重复、可审查、可追踪。

本教程只对应知识点 `snowflake-declarative-change-management`。目标是理解其机制、适用边界和验证方法，不把相邻知识点合并成一个大章。

### 将漂移、执行身份与失败恢复纳入发布审计

平台短期恢复能力、零拷贝克隆和长期业务历史保存解决不同问题。恢复前记录时间点、对象范围和影响面，在隔离副本验证后再执行生产恢复。

## 工程实施步骤

1. 明确 Git 版本、目标环境、部署身份、对象依赖和所需权限。
2. 先在低风险环境生成变更计划并运行静态、集成和数据验证。
3. 发布后核对对象定义、实际数据、运行指标和回滚点。
