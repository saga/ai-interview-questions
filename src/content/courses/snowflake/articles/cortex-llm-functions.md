## 常见误区

- **误区：** 简单任务默认用最大模型
  **纠正：** 模型输出先作为候选结果处理。分别验证格式/Schema、业务不变量、证据来源、低置信结果和异常样本，并记录模型/提示版本、输入范围、延迟和成本。
- **误区：** 认为 JSON 格式正确就代表语义正确
  **纠正：** 半结构化字段读取时区分字段缺失、JSON null、SQL NULL 和类型转换失败。FLATTEN 会把数组展开成行，必须检查展开前后的粒度和连接基数。
- **误区：** 只凭单一 demo 决定模型选型
  **纠正：** 模型输出先作为候选结果处理。分别验证格式/Schema、业务不变量、证据来源、低置信结果和异常样本，并记录模型/提示版本、输入范围、延迟和成本。
