# 批量与持续数据摄取

## 本节要解决的问题

根据文件/行事件和延迟要求选择摄取方式。

Snowflake 平台基础。区分持久化对象、计算资源、元数据服务、会话上下文和授权主体，再沿数据实际流动路径验证行为。

本教程只对应知识点 `snowflake-data-loading`。目标是理解其机制、适用边界和验证方法，不把相邻知识点合并成一个大章。

1. 确认对象类型、当前 Role、Warehouse、Database 和 Schema，避免把 Session Context 当成对象本身。
