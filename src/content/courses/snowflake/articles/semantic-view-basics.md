# Semantic View 基础组成

## 本节要解决的问题

用结构化语义描述业务实体、维度和指标.

Cortex GenAI 应用。明确任务输入、模型或检索路径、输出契约、质量指标、数据权限和失败处理。

本教程只对应知识点 `semantic-view-basics`。目标是理解其机制、适用边界和验证方法，不把相邻知识点合并成一个大章。

## 核心知识

### 用结构化语义描述业务实体、维度和指标.

业务指标必须定义分子、分母、过滤条件、时间口径、事实粒度和可加性。语义层能表达已确认的业务定义，却不能修复底层错误键、粒度或多对多关系。

## 常见误区

- **误区：** Semantic View 只能存原始文件
  **纠正：** 文件入口、文件解析和目标表写入必须分别验证。检查路径与文件清单、格式选项、列匹配、拒绝行、加载历史和目标行数；失败重跑前先确认之前是否已部分提交。
- **误区：** 语义定义可以不写关系和指标含义
  **纠正：** 业务指标必须定义分子、分母、过滤条件、时间口径、事实粒度和可加性。语义层能表达已确认的业务定义，却不能修复底层错误键、粒度或多对多关系。
- **误区：** 自然语言说明能替代所有 SQL 检查
  **纠正：** 业务指标必须定义分子、分母、过滤条件、时间口径、事实粒度和可加性。语义层能表达已确认的业务定义，却不能修复底层错误键、粒度或多对多关系。
