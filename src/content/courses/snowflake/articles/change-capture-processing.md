# Streams、Tasks 与 CDC 事务语义

## 本节要解决的问题

以 Stream offset 与变更记录实现 CDC，以 Task 编排处理。

Snowflake 平台基础。区分持久化对象、计算资源、元数据服务、会话上下文和授权主体，再沿数据实际流动路径验证行为。

本教程只对应知识点 `change-capture-processing`。目标是理解其机制、适用边界和验证方法，不把相邻知识点合并成一个大章。

## 核心知识

### Stream 不存完整源表副本，offset 与 DML 消费事务相关。

Stream 暴露的是自上次消费位置以来的变更视图，消费进度与事务提交相关。需要明确消费事务、目标幂等键和失败恢复流程，不能把它当无限期完整变更日志。

### Task 可按计划或 Stream 事件运行 SQL/存储过程。

Stream 暴露的是自上次消费位置以来的变更视图，消费进度与事务提交相关。需要明确消费事务、目标幂等键和失败恢复流程，不能把它当无限期完整变更日志。
