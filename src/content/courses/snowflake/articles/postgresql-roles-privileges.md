# PostgreSQL Roles、权限与最小权限

## 本节要解决的问题

使用 Role/Role Membership、对象权限、默认权限和 schema usage 管理用户访问，减少共享凭据和特权扩散。

PostgreSQL 数据库工程。依据 PostgreSQL 自身的事务、MVCC、WAL、索引、优化器和后台维护语义分析问题，不将 Snowflake 机制套用到 PostgreSQL。
