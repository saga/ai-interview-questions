## 常见误区

- **误区：** 把所有 DataFrame 操作都当成本地执行
  **纠正：** 回到本知识点的输入条件、执行边界和验证证据，确认判断成立的前提，不要把简化经验当普遍规则。
- **误区：** 忽视大结果集搬运导致的成本和内存风险
  **纠正：** 参数调整前区分实际内存分配与规划器估算值，并估算并发会话、多个执行算子和并行 Worker 的乘数效应。
