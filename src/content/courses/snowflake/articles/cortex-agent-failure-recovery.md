处理超时、部分成功、重复调用和不可逆副作用，定义安全重试与人工升级路径。

Cortex Agents、ML 与 CoCo。明确目标、工具/模型边界、身份授权、输入输出、执行证据、评测和停止条件。

## 常见误区

- **误区：** 对所有工具错误都使用相同的无限重试
  **纠正：** Agent 可靠性来自工具契约、调用身份、权限、停止条件、失败恢复和可审计轨迹。Thread 不是业务状态库；工具返回内容是待验证数据，不是系统指令。
- **误区：** 不查询执行状态就重放非幂等动作
  **纠正：** Agent 可靠性来自工具契约、调用身份、权限、停止条件、失败恢复和可审计轨迹。Thread 不是业务状态库；工具返回内容是待验证数据，不是系统指令。
- **误区：** 只向用户展示成功/失败而不保留恢复证据
  **纠正：** 平台短期恢复能力、零拷贝克隆和长期业务历史保存解决不同问题。恢复前记录时间点、对象范围和影响面，在隔离副本验证后再执行生产恢复。
