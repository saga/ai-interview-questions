# Agent 工具授权、用户身份与最小权限

## 本节要解决的问题

为 Agent 工具调用绑定可审计身份，并使模型决策不能绕过 Snowflake 的授权和数据策略。

Cortex Agents、ML 与 CoCo。明确目标、工具/模型边界、身份授权、输入输出、执行证据、评测和停止条件。

本教程只对应知识点 `cortex-agent-permission-boundary`。目标是理解其机制、适用边界和验证方法，不把相邻知识点合并成一个大章。
