# Snowflake Workspaces 与 Git 协作

## 本节要解决的问题

通过 Git 版本、分支和差异审查协作维护 SQL/Notebook，避免源文件与生产对象漂移。

Snowflake 工程交付与运维。重点是让配置、执行身份、变更、运行证据和恢复过程可重复、可审查、可追踪。

本教程只对应知识点 `sf-demo-git-workspaces`。目标是理解其机制、适用边界和验证方法，不把相邻知识点合并成一个大章。

1. 明确 Git 版本、目标环境、部署身份、对象依赖和所需权限。
