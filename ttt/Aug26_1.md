如果把一个知识领域：


直接蒸馏成：

那么确实会发生你说的问题：

```text

████████████████████████████████

         ↓ 蒸馏

       ●    ●
    ●       ●
          ●

大量知识点没有被任何题目触达
```

而且**增加到 20 道题也不是根本解决方案**。你真正需要的是：

> **让系统知道“这个知识领域的面到底有多大”，然后用有限的题目尽可能覆盖这个面。**

```text
   ↓
```

```text

```

---

## Mastery

> 对已经触达的知识，用户掌握得怎么样？

例如：

```text

5 strong

```



```text

```

意味着：

> **知识面已经测得很广，但很多地方掌握不牢。**

这两个状态完全不同。

你现在的 adaptive engine 会因此得到一个非常重要的新信号：


# 9. 题目选择可以变成一个“最大覆盖问题”

这其实是一个非常经典的算法问题。

假设：

```text
Knowledge concepts = 20

Question A → {1,2}
Question B → {3,4,5}
Question C → {6}
Question D → {2,7,8}
Question E → {9,10}
...
```

你只有：

```text
5 questions
```

那么不要：

> 每个 topic 随机抽 5 道。

而是：

> **选择 5 道题，让它们覆盖最多的重要 concept。**

这就是类似 **Weighted Maximum Coverage / Set Cover** 的问题。

而且你不需要上什么复杂算法。

一个 greedy 就够：

```text
while questionBudget > 0:

    找一题：
        新覆盖 concept 最多
        × concept importance
        × question quality
        × diversity

    选择它

    标记这些 concept 为 covered

    questionBudget--
```

---

# 10. 但“覆盖最多”也不是唯一目标

否则会出现：

```text
Q1 → concept A B C
Q2 → concept A B C
Q3 → concept A B C
Q4 → concept A B C
Q5 → concept A B C
```

理论上题目质量很高，但 coverage 很差。

所以你的 scoring 可以很简单：

```text
Question Utility =
    0.45 × newCoverage
  + 0.25 × importance
  + 0.15 × diagnosticValue
  + 0.10 × difficultyFit
  + 0.05 × diversity
```

不需要一开始就搞复杂的机器学习模型。

# 11. Concept 本身还应该有“重要性”

否则你会陷入另一个问题：

```text
一个知识领域有 100 个细节
```

系统为了追求 100% coverage，开始疯狂追问边角料。

所以：

```text
Concept
├── importance
├── prerequisite
├── category
└── coverage
```

例如 Transformer：

```text
self-attention
importance: 1.0

Q/K/V
importance: 1.0

RoPE
importance: 0.8

KV-cache
importance: 0.9

FFN
importance: 0.7

某个非常特殊的 positional encoding variant
importance: 0.2
```

于是：

```text
Coverage
```

不再是：

```text
7 / 20 = 35%
```

而是：

```text
sum(weight of covered concepts)
--------------------------------
sum(weight of all concepts)
```

可能得到：

```text
68%
```

这比单纯数 concept 更合理。

# 8. 第四步：计算 Coverage

这个可以非常简单。

假设：

```text
Transformer

A importance 1.0  ✓
B importance 1.0  ✓
C importance 0.8  ✓
D importance 0.7  ?
E importance 0.9  ?
```

Coverage：

```text
(1.0 + 1.0 + 0.8)
------------------
(1.0 + 1.0 + 0.8 + 0.7 + 0.9)

= 0.736
```

也就是：

```text
74%
```

实现：

```ts
function computeCoverage(
  concepts: Concept[],
  stats: Record<string, ConceptStats>
): number {
  let total = 0;
  let covered = 0;

  for (const concept of concepts) {
    total += concept.importance;

    const stat = stats[concept.id];

    if (stat && stat.attempts > 0) {
      covered += concept.importance;
    }
  }

  return total === 0
    ? 0
    : covered / total;
}
```

**第一版就做到这里。**

不要现在引入复杂的 coverage probability。

# 10. `selectNextConcept()` 怎么做？

先定义一个很简单的 score：

```text
Concept Priority =
    importance
  × coverageNeed
  × masteryNeed
```

其中：

### unseen

```text
coverageNeed = 1.0
```

### 已测但弱

```text
coverageNeed = 0.5
masteryNeed = 1.0
```

### 已经 strong

```text
coverageNeed = 0.1
masteryNeed = 0.1
```

第一版甚至可以简单到：

```ts
function conceptPriority(
  concept: Concept,
  stats?: ConceptStats
) {
  if (!stats || stats.attempts === 0) {
    return concept.importance * 1.0;
  }

  if (stats.avgScore < 85) {
    return concept.importance * 0.8;
  }

  return concept.importance * 0.1;
}
```

然后：

```ts
function selectNextConcept(
  concepts: Concept[],
  stats: Record<string, ConceptStats>
) {
  return [...concepts]
    .sort(
      (a, b) =>
        conceptPriority(b, stats[b.id]) -
        conceptPriority(a, stats[a.id])
    )[0];
}
```

这已经比随机抽题强很多。

# 21. 你甚至不需要实现 Set Cover 算法

直接 greedy：

```ts
function selectQuestions(
  candidates: Question[],
  concepts: Concept[],
  count: number
) {
  const selected: Question[] = [];
  const covered = new Set<string>();

  while (
    selected.length < count &&
    selected.length < candidates.length
  ) {
    const best = candidates
      .filter(q => !selected.includes(q))
      .map(q => ({
        question: q,
        gain: q.tests.reduce(
          (sum, test) => {
            if (covered.has(test.concept)) {
              return sum;
            }

            const concept = conceptsById[test.concept];

            return sum + concept.importance;
          },
          0
        ),
      }))
      .sort((a, b) => b.gain - a.gain)[0];

    if (!best) break;

    selected.push(best.question);

    for (const test of best.question.tests) {
      covered.add(test.concept);
    }
  }

  return selected;
}
```

第一版完全够用。
