## ★ 重要修正：`cjkDice` 是「token 多重集 Dice」，不是字符级

昨天在 MEMORY.md 里写成「字符级 Dice」，**不准确**。实读 `src/domain/textSimilarity.ts`：

- `cjkTokenize`：**中文按单字**切 token；**拉丁/数字按连续词**切（kebab-case / snake_case 拆词）；
  其余字符（空格、标点）当分隔符丢弃；整体小写化。
- `tokenMultisetDice`：`200 * |交集(多重集)| / (|A| + |B|)`；空对空 = 100。
- 于是 `drift 阈值 35`、`dup 阈值 88`（`VARIANT_DUP_THRESHOLD`）都是在这个口径上校准的。

**推论（写变体时必须记住）**：canonical 选项里若有**长拉丁词**（`temperature` / `prompt` /
`PreToolUse` / `hook`），它在 token 表里只占 **1 个 token**，但换成中文后
「温度」「提示词」等会展开成多个 token，交集骤降 → 极易跌破 35 被判 drift。
**对策：canonical 选项里的拉丁词原样保留**（可改周边的中文字），别把它翻译成中文。
这与「题干要避开正确项独有拉丁词（extra-hint）」并不矛盾——那条只作用于**题干**，
选项里保留拉丁词反而是保 drift 的正确做法。
