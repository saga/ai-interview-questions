## 存量 assessment 回填（用户点名修 "0/1354 题目、0/100 变体"）

### 诊断结论
- 不是 schema 缺字段，是**缺 producer**。新管线 `convert-blueprint-output.ts` 早已落库 Blueprint 的
  `assessmentTarget/reasoningGoal`（P0-2 已修），但存量 1354 题走旧管线，全空。
- 环境里**没有 LLM**：env 无 API key，localStorage 里那份 Node 读不到，127.0.0.1:8888 未起。
  ⇒ 只能离线抽取，不能生成。

### 做法（新增两个文件）
- `src/domain/assessmentInference.ts`（纯函数 + 10 条单测）：**只抽取不生成**。
  - target = 解析里的核心断言句，分句打分取最优（谓语信号 +2 / 长度 20~90 +2 / 命中正确项 +1 / 首句 +1）。
  - reasoningGoal = angle×cognitiveTask 起手动作 + 实际正确项摘要 + 干扰项摘要。
  - 抽不到断言句 → 返回 null（不用模板文本灌满，理由同 misconception 阈值 45）。
  - 排除：元信息行、`A 项…` / `A、B 项…` 判错句、干扰项复述（cjkDice ≥70 **或** token 覆盖 ≥80%）。
- `scripts/backfill-assessment.ts` → `npm run question:assessment`：默认报告，`--write` 回填，
  `--engine=infer|llm`，`--overwrite` 重建并**剪枝**，审计侧车 `temp/assessment-backfill-<date>.json`。

### 三个踩坑（按重要性）
1. **变体声明的测量意图与 canonical 雷同**：首轮写完 94 条变体后 validate-variants 报 31 条雷同。
   这些是 `surface-options`（选项没改写），推导必然一致 ⇒ 按 ADR-077 证明不了「不同 reasoning path」
   就**不该声明**（不声明=继承 canonical）。加全等比对后降到 0。**最终 52 自声明 / 48 继承。**
2. **cjkDice 被长句稀释**：干扰项复述判定只用 Dice 会漏过「…确实更灵活，但这不是动机」这种长句，
   必须补 token 覆盖率（干扰项 token 被句子覆盖 ≥80%）。
3. **`--overwrite` 必须能剪枝**：回填工具只 set 不 delete，改了推断规则后旧值会残留成矛盾状态。
   改成 `planned: Map<string, Assessment|undefined>`，undefined = 删。改规则后要跑**两遍**才收敛
   （第一遍 canonical 在磁盘上还是旧值，变体比对用的是旧 canonical）。

- 剩余 156 题须 LLM（`--engine=llm` 已留好，用 vite-node 跑，env 复用 CHALLENGER_*）。

### 人工判定口径（下次复核照这个来）
- 「下列说法正确的有」**按陈述性质分流**：定义/职责/机制 → `identify`；价值/考量/优势/缺陷分析 → `evaluate`。
- 「哪些措施 / 哪些设计 / 如何做」→ `design`；「为什么 / 原因 / 原理」→ `explain`。
- 「优先排查 / 最可能的原因」→ `diagnose`；「在哪些情形下会 X」→ `predict`。
- 「哪个方案满足需求」：**单能力层**（AIP 级选服务/指标）→ `apply`；
  **需组合多组件架构**（AWS Pro 级）→ `design`。

### 关键坑：改 cognitiveTask 会让变体变 stale（93 条）
`sourceHash` 对 `cognitiveTask` 是**条件入指纹**（`src/schemas/variant.ts`：未声明不出该键，
声明后变化即判 stale）。所以补写第四维 → 其变体全部 stale。**不是真的漂移**：变体文本没变，
变的是继承来的元数据，而 ADR-077 规定未自声明变体恒取 canonical 当前值。
正确处置 = **重设指纹**，不是重跑 `question-variants.ts`（那要 LLM key 且会改内容）。

新增 `scripts/refresh-variant-hash.ts`（`npm run question:variant-rehash`）：
仅当「旧指纹 == 去掉 cognitiveTask 后的指纹」才改写，其余判真实漂移并列出。
本次 93/93 属前者、0 条真实漂移、0 孤儿。
