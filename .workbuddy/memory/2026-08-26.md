## PR0 实验（已执行，验证通过）

- 执行 action list 的 PR0：对真实 `transformer` 节点 + `transformer.json`（43 题）做概念覆盖试点。
- 改动（最小可逆、零回归，tsc 绿 / 278 test passed）：`knowledgeNodeSchema` 加可选 `concepts[]`；`questionSchema` 加可选 `tests[]`；`llm-architecture.json` 的 `transformer` 节点挂 10 概念面；`tests` 暂存于 `scripts/pilot/transformer-concept-tests.json`（未污染生产题库）；新增 `scripts/pilot/coverage.mjs`（只读，加权覆盖计算）。
- 实测结论（全部验证 PR0 假设）：①43 题但仅 8/10 概念在本题库触达；②覆盖极度不均（self-attention 36 题次 vs residual-normalization 2）；③kv-cache 在 transformer.json 0 题、却在 model-architecture/inference 题库大量存在→概念跨 topic 泄漏，topic 级视图会漏概念；④反向缺口：ffn/residual-normalization/causal-mask/training-objective 被题考察但知识库无节点→Knowledge Set 比 Question Set 还粗，概念应作独立覆盖坐标系；⑤training-objective 仅作 supporting→弱覆盖陷阱。
- 加权覆盖率（本题库范围）81.5%，2 未覆盖（ffn/kv-cache 本库）+1 弱覆盖（training-objective）。
