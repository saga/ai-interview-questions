  - Rule B `pseudo-single-choice`：单选题干含「最准确/最贴切/最合适/最确切/最正确」→ 11 题。
  - Rule H `kitchen-sink-answer`：单选 + 正确项最长 + 长度比>1.8× + 正确项含≥2 个并列分隔符（、"+"以及同时与且；/）→ 27 题。**初版误报 381**（不限制题型/分句阈值），收紧为仅 single 后降到 27；多选的正确项本就是多条独立陈述，不属此类。
  - Rule I `strawman-distractor`：干扰项命中稻草人短语块（删测试/删库/只看token/完全自动化/完全相反/明显荒谬…）→ 3 题，抽查均为真稻草人。
