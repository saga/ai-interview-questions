### 自审抓到的事实错误（门禁 + 检测器全抓不到）

- 秩分离反例用错了成员：「主对角线为 0、其余全为正的 n 阶矩阵」里 `J−I` 的特征值是 `n−1` 与 `−1`，
  代数秩 = **n** 而不是常数；而 `rank₊ ≥ rank` 恒成立，原说法自相矛盾。
- 正确成员：n 个共线等距点的**平方距离矩阵** `M_ij=(i−j)²`，展开 `x²1ᵀ−2xxᵀ+1(x²)ᵀ` → 代数秩 ≤ 3（常数），
  非负秩随 n 对数级增长（Hrubeš 2012）。同族矩阵、不同成员，结论才成立。
- **教训：举反例时必须把具体矩阵代入算一遍，不能只凭「这是教科书例子」的印象。**
