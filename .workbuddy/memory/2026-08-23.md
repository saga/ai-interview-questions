# 2026-08-23

## 项目：AI 面试题训练器（ai-interview-questions）
从零搭建的 React 应用，技术栈与关键决策：
- **栈**：Vite + React 18 + TypeScript + Ant Design（实际装到 antd 6.6.1，非 v5）。
- **LLM 集成**：`@earendil-works/pi-ai@0.84.2`（npm 最新；旧文档的 `^0.4.10` 不存在）。
  - `complete()` 的 options 类型不含 `apiKey`；浏览器注入密钥走 `createModels({ credentials })` 传入内存 `CredentialStore`（read 返回 `{type:'api_key', key}`）。
  - provider id 固定为 `openai`/`anthropic`/`openrouter`，与 `getModel(provider, id)` 对应。
  - pi-ai 已对浏览器做兼容（`globalThis.process` 守卫、懒加载 `node:fs`），不会因 env/fs 崩溃。
- **题库**：`src/data/questions.json`，28 题，8 类别，含 single/multiple/essay 三类。
- **AI 功能**：出题变体（重新措辞+打乱选项+重算答案索引）、问答题评分（0-100 + 亮点/遗漏）。
- **CORS 提示**：浏览器直连 OpenAI/Anthropic 可能受限，默认推荐 OpenRouter。
