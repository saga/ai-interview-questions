## Copilot 侧边栏 AI 回答 100% 宽度 + 去阴影

用户要求 AI Copilot 的回答（`placement='start'`）撑满宽度且不要阴影。多次尝试后发现根因是 ant-design/x `Bubble.List` 的默认样式给 `ant-bubble-start` 加了 `padding-inline-end: 15%`，这是导致右侧留白的元凶。

修改 `src/components/copilot/CopilotSidebar.tsx`：
- `assistant` 角色加 `classNames.root='copilot-assistant-bubble'`、`classNames.content='copilot-assistant-message'`。
- 注入 `<style>` 覆盖：
  - `.copilot-assistant-bubble.ant-bubble-start { padding-inline-end: 0 !important; }`
  - `.copilot-assistant-bubble .ant-bubble-body { width: 100% !important; }`
  - `.copilot-assistant-message.ant-bubble-content { width:100%; max-width:100%; box-shadow:none !important; }`

浏览器实测：root/body/content 宽度一致（331px，即内容区可用宽度），`box-shadow: none` 生效。

注意：antd-x Bubble 的 `styles.content.width` 会受外层 `body` 和列表默认 padding 制约，只改 content 不够。
