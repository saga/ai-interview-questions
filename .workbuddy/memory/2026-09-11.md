## Agent 面试加每题倒计时 + 时间到弹窗

用户反馈：Agent 面试没有倒计时提醒，且会「突然跳到下一题」。实际排查：Agent 面试**本来就没有任何倒计时**
（只有模拟面试 `useTrainingSession` 有 30min 整场倒计时会自动交卷）。按需求实现：

- `useAgentInterview` 新增每题倒计时，常量 `AGENT_QUESTION_TIME_LIMIT_SEC = 180`，每道交付题重置。
  busy/submitting 期间冻结计时（面试官思考/评分不消耗作答时间）；finalize/restart/endEarly/卸载均清定时器。
- 时间归零**不自动跳题**，改弹 `Modal`（不可点遮罩关）：「延长本题时间（再 180s）」或「跳到下一题（放弃本题，走 Agent 的 `skip()`，不计分）」。
- UI：`AgentInterviewPage` 运行态头部加「本题剩余 mm:ss」标签（green>60 / gold>30 / red 其余）。
- 新字段经 `AgentInterviewState` 接口透传；App 用 `{...agent}` 展开，自动带到页面。
- 自检：`tsc -p tsconfig.app.json` 通过；`src/agent` 106/106 测试通过。
