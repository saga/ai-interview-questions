# 大学生校招初级与中级题目扩展：150 题

更新日期：2026-11-24

本批在现有校招课程中新增 150 道题，沿用原有 15 个知识主题，每个主题 10 题。面向本科应届生和研究生应届生，使用课程项目、毕业设计、科研、竞赛、开源、实习和求职沟通场景，不要求候选人必须拥有大厂实习经历。

## 难度与题型

| 难度 | 数量 | 主要考察 |
|---|---:|---|
| 初级 | 75 | 识别基本原则、选择合适行动、理解常见求职和协作场景 |
| 中级 | 75 | 信息不完整时分析问题，在时间、质量、责任和利益相关方之间作出权衡 |
| **合计** | **150** | |

题型包括 45 道单选和 105 道多选。所有题目为四选项，单选一个正确答案，多选三个正确答案。新批次多选占 70%，避免将多个独立判断压缩成“最正确的一项”。

## 覆盖方法

这批题目不是方法名词测验。方法被放入具体场景，考生需要判断什么时候使用、需要哪些信息、有哪些局限，以及如何验证结果。

| 方法 | 对应训练内容 |
|---|---|
| STAR | 把项目和行为经历讲清楚，区分背景、目标、本人责任、行动和结果 |
| PREP | 先表达观点，再用理由和实例支持，最后回到结论 |
| 金字塔原理 | 先给结论，再分层说明依据，控制自我介绍和项目汇报长度 |
| MECE | 拆解问题时减少分类重叠和关键因素遗漏 |
| 5W2H | 把模糊任务澄清为目标、范围、时间、资源和验收条件 |
| 5 Whys | 从表面现象沿因果链追问，避免停留在个人归因 |
| 第一性原理 | 检查习以为常但尚未验证的前提，从目标和事实重新分析 |
| 假设驱动分析 | 形成可检验假设，先用低成本证据验证再扩大行动 |
| 积极倾听 | 复述对方关切，区分用户表达的方案与真正问题 |
| SMART | 将学习或交付目标定义为具体、可衡量、有期限的结果 |
| 艾森豪威尔矩阵 | 区分重要与紧急，综合价值、依赖和风险安排优先级 |
| 反馈与复盘 | 把评价转成具体行为改进，并追踪结果 |
| 决策矩阵 | 比较岗位、城市和 Offer 时显式说明权衡标准 |
| AI 素养 | 核验 AI 输出，处理隐私、许可证和代码质量责任 |

同时覆盖求职动机、岗位认知、个人定位、团队协作、冲突处理、可靠交付、业务意识、职业伦理和科研经历向工程实践的迁移。

## 题库集成

题目文件：

`src/data/questions/campus-employment-150-foundation-intermediate.json`

题目 ID：`ce-practice-001` 至 `ce-practice-150`。

每题均关联现有校招知识节点，提供难度、考察角度、认知任务、来源说明、常见误解、答案和解析。所有题目使用 `practice-extension` 标签和课程设计来源标识，明确它们是教学练习，不冒充企业真实面试原题。

数据文件通过现有 `src/data/questionBank.ts` 的 JSON glob 自动加载，不需要新增 taxonomy、课程知识节点或独立页面。题库覆盖和统计见[785 题覆盖说明](./campus-employment-question-coverage-785.md)。
