# 校招面试题库 650 题覆盖说明

更新日期：2026-11-24

## 题量与难度

目前校招课程共有 **650 道情境式选择题**，均为四选项题，不包含开放题。

| 批次 | 初级 | 中级 | 高级 | 合计 |
|---|---:|---:|---:|---:|
| 基础题库 | 180 | 120 | 0 | 300 |
| 2025–2026 面试模式扩展 | 0 | 100 | 100 | 200 |
| 本次初/中级扩展 | 75 | 75 | 0 | 150 |
| **合计** | **255** | **295** | **100** | **650** |

本次新增题目只覆盖初级和中级，初级侧重识别基本原则、选择合理行动；中级侧重在信息不完整、约束冲突或需要权衡的情境下作出判断。没有把题目难度简单等同于题干长度。

## 题型分布

全库共 **420 道单选、230 道多选**。本次新增批次包含 45 道单选和 105 道多选，多选占本批 70%，符合新增题以多选为主的题型要求。历史题库保留原有分布，因此全库多选比例为 35.4%。

单选用于存在一个最佳行动或判断的情境；多选用于识别多个能够独立成立的行动、证据或约束。每题均有四个选项，多选题有三个正确项和一个干扰项，少选、错选或多选均判错。

## 本次新增内容

本批题目覆盖前面课程分析中的主要方法和能力，并将方法放在具体情境中考察，而非只问术语定义。

| 主题 | 覆盖方法或判断能力 |
|---|---|
| 求职动机与岗位认知 | 岗位职责核实、个人能力与 JD 匹配、选择依据 |
| 自我介绍与个人定位 | STAR 经历组织、PREP、金字塔原理、证据化表达 |
| 项目与个人贡献 | STAR、指标基线、结果验证、个人贡献边界 |
| 团队协作 | 角色分工、接口交接、协作失衡、团队责任 |
| 沟通冲突 | 积极倾听、PREP、事实与观点区分、决策记录 |
| 可靠交付 | 5W2H、验收标准、风险同步、质量复核 |
| 问题解决 | MECE、5 Whys、假设驱动分析、第一性原理 |
| 学习与 AI 素养 | 学习闭环、输出核验、隐私、许可证 |
| 时间与压力 | 艾森豪威尔矩阵、SMART、风险和依赖排序 |
| 自我认知 | 反馈澄清、复盘、行为证据、改进追踪 |
| 业务意识 | 用户需求、成功指标、成本收益权衡 |
| 职业伦理 | 数据最小化、诚信、知识产权、风险报告 |
| 面试表达 | 问题澄清、未知边界、追问、有效反问 |
| Offer 决策 | 决策矩阵、总薪酬、城市成本、合同条件 |
| 经历迁移 | 科研与工程差异、复现、成果署名和贡献边界 |

## 情境与来源边界

- 本次题目统一使用 `practice-extension` 标签，来源标记为课程设计练习，不声称是某家企业的真实面试原题。
- 题目情境来自课程项目、毕业设计、实验室、竞赛、开源协作、实习和校招沟通等应届生能够遇到的场景。
- 公开面经只用于识别考察模式，不代表企业统一题库，也不据此推断某题的出现概率。
- 题干、四个选项、答案和解析均自包含，不要求考生阅读某篇外部文章后才能作答。

## 数据约束与质量检查

- 使用 `courseId: campus-employment`，与 AI 的六个能力域 taxonomy 隔离。
- 每题的 `topic` 和 `knowledgeId` 均对应现有校招课程知识节点；本次没有增加知识节点或改变 UI。
- 每题只提供 `formats.choice`，不提供开放题形态；难度只使用 `easy` 和 `medium`。
- 本批 150 题的题型为 45 单选、105 多选；每题四个选项，单选恰有一个答案，多选恰有三个答案。
- 题目包含 `angle`、`cognitiveTask`、来源章节、常见误解和选项误解映射，供题库检索与训练反馈使用。
- 新增题的选项长度比例不超过 1.7；正确项与干扰项均长差绝对值不超过 8；单选正确项不比最长干扰项长超过 4 个字符。
- 本批答案位置均衡：单选正确位置分布为 12/11/11/11；多选干扰项位置分布为 27/26/26/26。
- 新增题 ID 为 `ce-practice-001` 至 `ce-practice-150`。
