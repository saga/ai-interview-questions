## 数据结构与边界

- 所有 300 道题的 `courseId` 为 `snowflake`；题目 `topic/knowledgeId` 指向可追溯的知识节点，`category` 使用 Snowflake 自有的八个主题之一，不扩展 AI 原有六大 taxonomy。
- 每道题具备四个选项、答案索引、误解映射、开放题参考答案，以及 `source.materialId`、`source.section`、`source.relatedMaterials`。
- 题目覆盖机制、设计、诊断、取舍、Runbook 和验收证据等不同视角；选择题混合单选与多选。每个知识点恰有 5 道新题。
- 课程公开模块主题用于教学路线归属；技术行为以本文件列出的 Snowflake 官方文档 ID 为准。完整 URL 目录见 [Snowflake Course Roadmap](./snowflake-course-roadmap.md)。
- 21 个新增知识点重点补足 Iceberg Catalog/manifest/并发迁移、Cortex 模型与 SQL 安全、检索和 Analyst 评测、Agent 授权/恢复/评估以及 CoCo 上下文、优化和治理。
